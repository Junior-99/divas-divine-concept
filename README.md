# Devas Divine — independent website concept

Six-page React/Vite beauty editorial concept, not commissioned by or affiliated with the salon. Public first-party Facebook page uses Devas Divine hair and beauty salon; directory spelling differs. Current page lists Ngong Road, Woodley Estate, Nairobi; confirm current services, prices and times directly.

## Run

`npm ci`, `npm run dev`, `npm run build`. Deploy dist to GitHub Pages with relative assets.

## Features

353 public Facebook feed images with original photo links; eleven larger hairstyle originals; paginated archive, persistent style shortlist, appointment brief validation, local drafts/status/notes, JSON export, scroll-responsive original Three.js style mobile with drag and reduced-motion support. Shared Supabase creator inbox has explicit demonstration consent and authenticated membership-enforced access. No confirmed booking or business notification. Local drafts stay in this browser.
